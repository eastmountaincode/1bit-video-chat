# Hydra example sketches

These sketches are from the Hydra editor's published homepage examples:
https://github.com/hydra-synth/hydra/blob/523e0feaf3f49899b759ce0e7afabe0114ddfe2b/src/stores/examples.json

The original author names and links remain in each sketch's comments. The
decoded sketch code is unchanged. Telepathy includes 49 of the 58 examples;
the nine that require audio analysis or camera/source input are excluded.
